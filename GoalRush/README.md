# GoaLRush

## Запуск сайта

Составы сохранены локально в `players-data.js`. Ключи, API-запросы и интернет
для просмотра игроков не нужны.

1. Дважды нажмите `start-site.bat`.
2. Откройте `http://localhost:8080/`.
3. Перейдите в раздел «Футболисты» и выберите лигу и клуб.
4. Наведите курсор на карточку игрока для краткой подсказки или нажмите на нее,
   чтобы открыть окно с подробностями.

Списки клубов и составы обновлены по данным ESPN на 29 октября 2026 года.
В файл включено по 15 игроков для клубов доступных лиг: Англии, Италии,
Испании, Германии, Франции, Нидерландов, Португалии, Бельгии и Турции.
Чешская лига исключена, так как источник не предоставил данные клубов.

В разделе «Чемпионаты» можно выставить каждой лиге и Лиге чемпионов оценку
от 0 до 100 с помощью ползунка. Средняя оценка и ваш голос сохраняются в
локальном хранилище браузера на этом устройстве.

`server.ps1` запускает только локальный статический сервер и не запрашивает
учетные данные или внешние API.
